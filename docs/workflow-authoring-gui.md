# Workflow 写作 GUI 规范

## 1. 目标与边界

Workflow 写作界面采用“克制专业、均衡密度、桌面优先”的视觉语言。规范覆盖三栏工作台、字段编辑、CLI/Log/Config 采集、Schema、同步和单步调试，不改变 Workflow 数据结构、编辑流程或校验语义。

本轮不提供暗色主题或手机布局。低于桌面最小宽度时允许页面级横向滚动，但局部控件不得重叠或产生非预期横向滚动。

## 2. 设计基础

### 颜色

| 语义 | 用途 |
| --- | --- |
| 白色与浅灰 | 主工作面、分区和代码背景 |
| 蓝色 | 选中、焦点和唯一主操作 |
| 绿色 | 成功、已完成和可同步状态 |
| 橙色 | 提醒、未保存和等待处理 |
| 红色 | 校验错误、执行失败和危险操作 |

颜色必须通过 `styles/features/workflow/tokens.css` 中的 `--wf-*` token 使用。普通分区使用留白和分隔线，不以阴影或彩色背景划分层级；阴影仅用于 Modal、浮动控件和选中反馈。

### 字体与控件

- 正文和输入为 `13px`，字段标签和辅助信息为 `11px`。
- 局部标题为 `15px`，编辑页标题为 `20px`。
- 字符间距固定为 `0`。
- 变量名、表达式、SQL、配置匹配模式、JSON 和设备回显使用 `--mono-font`。
- 输入框高度为 `40px`，普通按钮为 `36px`，图标按钮为 `32px`。
- 圆角最大为 `8px`；焦点状态统一使用 `--wf-focus-ring`。

## 3. 三栏工作台

| 视口宽度 | 结构栏 | 编辑区 | 预览栏 |
| --- | --- | --- | --- |
| `>= 1440px` | `252px` | 自适应 | `440px` |
| `1180-1439px` | `232px` | 自适应 | `360px` |
| `< 1180px` | 保持桌面基线并允许页面横向滚动 |

- 工具栏依次表达上下文、保存状态、编辑工具和发布命令；保存是唯一主按钮。
- 结构栏仅显示节点名称。选中、起点、错误和结论使用不同语义状态，排序操作只在 hover、focus 或选中时强调。
- 编辑区正文宽度稳定，页头、分区标题和字段节奏保持一致，避免把页面分区做成层层卡片。
- 右侧常驻流程图、阅读视图和校验 Tab；错误和提醒显示数量及对应语义颜色。
- 分隔条必须可发现，拖拽、折叠和流程图展开行为保持不变。

## 4. 编辑器与复杂结构

- 基础信息、全局输入、设备角色、步骤和结论共用相同的页头、标签、说明和操作区层级。
- 字段表格统一列宽、错误位置和空状态；删除、Schema 编辑等次要操作使用图标和 Tooltip。
- CLI、Log、Config 使用一致的采集定义页头、类型标识、输入输出和样例区。
- Query、Config command 和递归 Schema 以标题、缩进和左侧层级线表达嵌套，不创建装饰性卡片嵌套。
- 表达式、SQL、pattern 和 JSON 编辑器共用代码字体、行高、焦点环、错误和只读外观。
- 可定位错误紧邻控件展示；页面级反馈只承载无法定位的操作失败。
- 只读状态保留信息层级，编辑入口保持明确禁用或在无意义时隐藏。

## 5. Modal 与状态

- Workflow Modal 使用统一标题区、可滚动正文和稳定底部操作区，关闭按钮位于右上角。
- 确认弹窗保持紧凑；Schema、同步和单步调试使用工作区尺寸。
- Schema 突出类型、属性树和 JSON 预览；单步调试保持案例、编辑和结果三栏。
- loading、dirty、成功、错误、空状态、只读和禁用原因使用统一语义色与文字层级。
- 动效限制在 `120-180ms` 的淡入、选中和折叠反馈，并在 `prefers-reduced-motion: reduce` 下关闭。

## 6. 验收清单

- 在 `1440x900`、`1280x800`、`1180x720` 和 `1024x768` 下无文字遮挡、按钮跳动和表单错位。
- 局部面板没有非预期横向滚动；小于 `1180px` 时仅允许工作台整体横向滚动。
- 键盘导航、Tooltip、焦点环和 Modal 焦点管理可用。
- 三栏拖拽、折叠、预览展开、保存、同步和调试流程行为不变。
